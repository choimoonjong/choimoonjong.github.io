## Main Project

### 2025 Capstone Project - Web-based MMORPG

3인 팀으로 약 1년간 진행한 웹 기반 MMORPG 졸업작품입니다.

- **Role:** Web / Backend Development
- **Backend:** Node.js / Express
- **Database:** MySQL
- **Cloud:** AWS
- **Project Type:** 3-person Team Project

### 주요 경험

- 웹 페이지와 백엔드 서버 간 데이터 연동
- MySQL 기반 사용자 및 게임 데이터 처리
- 서버와 데이터베이스 간 데이터 저장 및 조회 과정 확인
- 프로젝트 진행 중 발생한 데이터 오류의 원인 분석 및 개선
- 서로 다른 개발 영역을 담당한 팀원들과 기능 및 데이터 연동 방식 조율

### Troubleshooting

게임에서 획득한 아이템과 재화가 재접속 후 이전 상태로 돌아가는 문제가 발생했습니다.

데이터 저장 과정을 확인한 결과, 변경된 데이터가 데이터베이스에 반영되기 전에 접속이 종료되는 경우가 있음을 확인했습니다.  
이후 데이터 변경 시점에 서버를 통해 저장하도록 처리 방식을 수정하고,  
**아이템 획득 → 로그아웃 → 재접속** 과정을 반복하여 데이터가 정상적으로 유지되는지 확인했습니다.
