About Me

컴퓨터공학 전공 과정에서 웹과 백엔드 개발을 경험했으며, 3인 팀으로 약 1년간 웹 기반 MMORPG 졸업작품을 진행했습니다.

프로젝트에서는 게임 클라이언트가 아닌 웹 홈페이지와 백엔드 개발에 참여하여 Node.js, Express, MySQL, AWS를 활용한 서버 및 데이터베이스 연동을 경험했습니다.

개발 과정에서는 기능을 구현하는 것뿐만 아니라, 데이터가 의도한 방식으로 저장되고 전달되는지 확인하고 문제가 발생했을 때 데이터 흐름과 발생 조건을 추적하여 원인을 찾는 과정을 중요하게 생각했습니다.

또한 Python과 YOLO를 활용한 프로젝트를 통해 이미지 데이터와 객체 탐지 기술을 경험하며 소프트웨어 개발 역량을 확장해 왔습니다.
